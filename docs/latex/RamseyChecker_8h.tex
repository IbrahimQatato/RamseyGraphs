Checks whether a 2-\/colored graph satisfies the Ramsey property for R(s,t). 

A coloring satisfies R(s,t) if it contains a red clique of size s OR a blue clique of size t. A coloring that satisfies neither is a counterexample — proof that more nodes are needed.
