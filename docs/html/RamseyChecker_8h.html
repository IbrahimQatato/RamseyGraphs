Advances index_vector to the next combination of k elements from n.

Uses the standard combination enumeration algorithm — finds the rightmost index with room to increment, increments it, resets everything to its right. Called repeatedly by hasClique.

Parameters
index_vectorCurrent combination indices, modified in place.
nTotal number of elements to choose from.
Returns
true if a next combination exists, false if all exhausted.

Checks whether a 2-colored graph satisfies the Ramsey property for R(s,t).

A coloring satisfies R(s,t) if it contains a red clique of size s OR a blue clique of size t. A coloring that satisfies neither is a counterexample — proof that more nodes are needed.

Template Parameters
NDataNode data type — must satisfy GraphData concept.
Parameters

Returns
true if the coloring contains a red K_s or blue K_t.

Checks whether a 2-colored graph contains a monochromatic clique.

Tries every C(n, clique_size) subset of nodes using combination enumeration. Returns true on the first subset where all edges between members have the given color.
